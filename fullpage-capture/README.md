# Fullpage Capture

ページ全体をスクロールしながらキャプチャ (またはクリップボードの画像を貼り付け) し、切り抜き・注釈・黒塗りをしてから PNG 保存 / クリップボードコピーする Chrome 拡張。GoFullPage の必要な部分だけを自作したもの。

- 外部通信なし (ネットワーク API を一切使っていない)
- 依存ライブラリなし (素の JS + Canvas)
- 権限は `activeTab` / `scripting` / `unlimitedStorage` / `contextMenus` のみ。アイコンを押したタブにしかアクセスしない
- クリップボードは自分で `⌘V` したときだけ読む (クリップボード読み取り権限は持たない)

## インストール

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」でこのディレクトリ (`fullpage-capture/`) を選ぶ

コードを変更したら、`chrome://extensions` でこの拡張の更新ボタン (↻) を押す。

ショートカット (`⌘⇧S` / `⌘⇧E`) は初回インストール時にだけ自動で割り当てられる。効かないときや変えたいときは `chrome://extensions/shortcuts` で設定する。

## 使い方

1. キャプチャしたいタブで拡張アイコンを押す (または `⌘⇧S`)
2. バッジに進捗 (%) が出る。終わるまでタブを切り替えない
3. 隣のタブに編集画面が開く

### クリップボードの画像を編集する

1. 編集画面を開く: `⌘⇧E`、または拡張アイコンを右クリック →「クリップボードの画像を編集」
2. `⌘V` で貼り付け (画像ファイルのドラッグ&ドロップでも可)

すでに開いている編集画面で `⌘V` しても、その画像に置き換わる (編集途中なら確認が出る)。
貼り付けた画像は Retina などこの画面の倍率で撮ったスクショとみなして、線の太さを合わせる。

### 描いた図形を動かす

選択ツールに切り替える必要はない。どのツールのままでも、描いた図形の上をドラッグすれば動かせる (Skitch と同じ)。

- 図形の上をドラッグすると移動する。矢印は先端や根元の丸を掴むと、その端だけ動かせる
- 描いた直後の図形は選択された状態になる。選択中の図形は、色見本・線の太さ・文字サイズを変えるとその図形に反映される
- `Delete` / `Backspace` で削除、`Esc` で選択を解除する
- 矩形は枠線の上だけ掴める。内側からは新しい図形を描き始められる
- 切り抜きより前に描いた図形は動かせない (切り抜きで座標が変わるため)

### 編集画面のショートカット

| キー | 動作 |
|---|---|
| `C` | 切り抜き |
| `R` | 矩形 |
| `A` | 矢印 (Skitch 風: 先へ向かって太くなる胴体 + 白フチ + 影) |
| `T` | テキスト (クリックした位置に入力。`Enter` 確定 / `Shift+Enter` 改行 / `Esc` 取消) |
| `H` | 蛍光ペン |
| `B` | 黒塗り |
| `M` | モザイク |
| `1`〜`8` | 色を選ぶ (赤 / オレンジ / 黄 / 緑 / 青 / 紫 / 黒 / 白)。最後に使った色を覚えておく |
| `⌘Z` / `⌘⇧Z` | 元に戻す / やり直し (移動・色変更も戻せる) |
| `Delete` / `Esc` | 選択中の図形を削除 / 選択解除 |
| `⌘C` | クリップボードにコピー |
| `⌘S` | PNG で保存 |
| `⌘V` | クリップボードの画像に置き換え |

黒塗り・モザイクは画像のピクセル自体を書き換えるので、保存・コピーした画像から元の内容は戻せない。個人情報など確実に隠したいものは、モザイクより黒塗りを使う。

## 仕組み

```
background.js  アイコン押下 → ページを 1 画面ずつスクロール → captureVisibleTab で撮影
               → OffscreenCanvas で縦に貼り合わせ → IndexedDB に保存 → editor.html を開く
editor.js      IndexedDB から読み込み → 撮影画像 + 操作リスト (ops) を canvas に描画
db.js          両者で共有する IndexedDB (直近 10 件だけ残す)
icons/         icon.svg が元。PNG は SVG から書き出したもの
```

- 2 枚目以降は `position: fixed / sticky` の要素を一時的に隠し、追従ヘッダーが何度も写り込むのを防ぐ。撮影後は元に戻す
- `captureVisibleTab` は 1 秒 2 回までの制限があるため、1 コマ約 0.6 秒かかる

## 制限

- `chrome://` ページや Chrome Web Store ではキャプチャできない (Chrome の仕様)
- ページ全体ではなく内側の枠がスクロールするサイト (Gmail、一部の管理画面など) は、見えている範囲しか撮れない
- 高さが約 32,000px (Retina では約 16,000 CSS px) を超えるページは途中で切れる (canvas の上限)。編集画面に警告が出る
- 途中の位置に置かれた sticky 要素 (追従サイドバーなど) は、2 枚目以降で消える
- スクロールに合わせて読み込みが続くページは、撮影開始時点の高さまでしか撮らない
