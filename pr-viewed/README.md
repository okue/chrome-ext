# PR Auto Viewed (difit rules)

GitHub PR の **Files changed** を開いたときに、[difit](https://github.com/yoshiko-pg/difit) と同じルールで「レビュー不要なファイル」を自動で **Viewed** にする Chrome 拡張。GitHub ネイティブの Viewed なので折りたたまれ、状態も GitHub 側に保存される。

- 送信先は github.com / patch-diff.githubusercontent.com / raw.githubusercontent.com のみ (外部サービスへの送信なし)
- 依存ライブラリなし
- 権限は `storage` と上記 3 ホストのみ

## インストール

[ルートの README](../README.md#インストール-共通) の手順で、このディレクトリ (`pr-viewed/`) を読み込む。

## 自動 Viewed になるファイル (difit と同じ)

| 種別 | 例 |
|---|---|
| 削除されたファイル | — |
| パスで判定する生成物 | `package-lock.json` `pnpm-lock.yaml` `go.sum` `go.mod` `uv.lock` … / `*.min.js` `*.map` `*.pb.go` `*.g.dart` `*.generated.ts` `mock_*.go` / `vendor/` `dist/` `**/generated/**` など |
| `.gitattributes` の `linguist-generated` | ルートの `.gitattributes` のみ対応 |
| ファイル先頭 20 行の目印 | `@generated` `DO NOT EDIT` `Code generated ... DO NOT EDIT.` `<auto-generated>` など (`.md` は除外) |
| 追加パターン (オプション画面) | difit の auto-viewed patterns と同じ glob 書式 |

判定ロジックは difit の `generated-file-check.ts` / `autoViewedPatterns.ts` の移植 (`lib/generated.js`)。difit 本家のテストケースで同じ結果になることを確認済み。

## 使い方

- PR の Files changed (`/pull/N/files` または新 UI の `/pull/N/changes`) を開くだけ
- ツールバーアイコンのバッジ = 対象ファイル数。ホバーで対象一覧と理由を表示する
- **一度自動 Viewed にしたファイルは覚えておき、手で Unview したら再度は付けない** (そのファイルに新しい変更が push された場合は再判定する)
- アイコンをクリックすると、この記憶を無視して現在の PR に再適用する
- 右クリック → オプションで、有効 / 無効・先頭行チェック・追加パターンを設定できる

### 左のファイルツリー

- 各ファイル・フォルダにチェックボックスを表示する。Viewed のファイルは薄く表示する
- フォルダは配下が全部 Viewed なら ✓、一部なら −。クリックで配下をまとめて Viewed / 解除する
- ツリーから切り替えても GitHub ネイティブの Viewed が変わる
  - 差分が表示中 → そのファイルの Viewed ボタンを押す
  - 新 UI で画面外 → GitHub と同じ `file_review` POST (Viewed にする場合)
  - それ以外 (画面外の解除、旧 UI の未読み込みファイル) → そのファイルへジャンプしてから押す
- 状態が分かるのは「一度でも差分が DOM に載ったファイル」と「この拡張が操作したファイル」だけ。まだ見ていないファイルは Viewed でも未チェックに見えることがある (ホバーで「状態未取得」と出る)
- 折りたたまれたフォルダは中身が描画されないので判定できない

## 仕組み

```
background.js      PR の .diff を取得・パースして判定。バッジ更新
content.js         対象ファイルの GitHub の Viewed チェックボックス / ボタンを押す
bridge.js          ページの MAIN world で動く。新 UI の React ボタン呼び出しと file_review POST
tree-status.js     左のファイルツリーにチェックボックスを出す (+ tree-status.css)
options.html/.js   オプション画面
lib/generated.js   difit から移植した生成ファイル判定
lib/diff.js        diff パーサ
lib/dom.js         GitHub の DOM 操作ヘルパ
lib/settings.js    設定の読み書き (chrome.storage)
lib/bridge-client.js  content.js / tree-status.js から bridge.js を呼ぶクライアント
```

- `background.js` は `github.com/<o>/<r>/pull/<n>.diff` をログイン中の Cookie で取得する。diff に 1 行目が含まれないファイルだけ `github.com/<o>/<r>/raw/<headSha>/<path>` の先頭 4KB を読む (最大 200 ファイル)
- `bridge.js` の手法は [gh-pr-auto-viewer](https://github.com/amitaifrey/gh-pr-auto-viewer) (MIT) を参考にしている。仮想スクロールで DOM に無いファイルは、GitHub のボタンと同じ `POST /pull/<n>/file_review` を送る

## 制限

- GitHub の DOM / 内部エンドポイントに依存しているため、GitHub の UI 変更で壊れる可能性がある。うまく動かないときは DevTools の Console で `[pr-viewed]` のログを確認する
- 巨大な PR で `.diff` が取得できない場合はバッジが `!` になり、何もしない
- ネストした `.gitattributes` は見ない
