# PR Auto Viewed (difit rules)

GitHub PR の **Files changed** を開いたときに、[difit](https://github.com/yoshiko-pg/difit) と同じルールで
「レビュー不要なファイル」を自動で **Viewed** にします（GitHub ネイティブの Viewed なので折りたたまれ、状態も GitHub に保存されます）。

## 自動 Viewed になるファイル（difit と同じ）

| 種別 | 例 |
|---|---|
| 削除されたファイル | — |
| パスで判定する生成物 | `package-lock.json` `pnpm-lock.yaml` `go.sum` `go.mod` `uv.lock` … / `*.min.js` `*.map` `*.pb.go` `*.g.dart` `*.generated.ts` `mock_*.go` / `vendor/` `dist/` `**/generated/**` など |
| `.gitattributes` の `linguist-generated` | ルートの `.gitattributes` のみ対応 |
| ファイル先頭 20 行の目印 | `@generated` `DO NOT EDIT` `Code generated ... DO NOT EDIT.` `<auto-generated>` など（`.md` は除外） |
| 追加パターン（オプション画面） | difit の auto-viewed patterns と同じ glob 書式 |

判定ロジックは difit の `generated-file-check.ts` / `autoViewedPatterns.ts` の移植（`lib/generated.js`）。
difit 本家のテストケースで同じ結果になることを確認済み。

## インストール

1. `chrome://extensions` → デベロッパーモード ON
2. 「パッケージ化されていない拡張機能を読み込む」→ この `pr-viewed/` ディレクトリを選択

## 使い方

- PR の Files changed（`/pull/N/files` または新 UI の `/pull/N/changes`）を開くだけ。
- ツールバーアイコンのバッジ = 対象ファイル数。ホバーで対象一覧と理由を表示。
- **一度自動 Viewed にしたファイルは覚えておき、手で Unview したら再度は付けません**（そのファイルに新しい変更が push された場合は再判定）。
  アイコンをクリックすると、この記憶を無視して現在の PR に再適用します。
- 右クリック → オプションで、有効/無効・先頭行チェック・追加パターンを設定。

### 左のファイルツリー

- 各ファイル・フォルダにチェックボックスを表示。Viewed は薄く表示。
- フォルダは配下が全部 Viewed なら ✓、一部なら −。クリックで配下をまとめて Viewed / 解除。
- ツリーから切り替えても GitHub ネイティブの Viewed が変わる：
  - 差分が表示中 → そのファイルの Viewed ボタンを押す
  - 新 UI で画面外 → GitHub と同じ `file_review` POST（Viewed にする場合）
  - それ以外（画面外の解除、旧 UI の未読み込みファイル）→ そのファイルへジャンプしてから押す
- 状態が分かるのは「一度でも差分が DOM に載ったファイル」と「この拡張が操作したファイル」。
  まだ見ていないファイルは Viewed でも未チェックに見えることがあります（ホバーで「状態未取得」）。
  折りたたまれたフォルダは中身が描画されないので判定できません。

## 仕組み

- `background.js`: `github.com/<o>/<r>/pull/<n>.diff` をログイン中の Cookie で取得してパースし判定。
  diff に 1 行目が含まれないファイルだけ `github.com/<o>/<r>/raw/<headSha>/<path>` の先頭 4KB を読む（最大 200 ファイル）。
- `content.js`: 対象ファイルの GitHub の Viewed チェックボックス／ボタンを押す。
- `bridge.js`（ページの MAIN world）: 新 UI の React ボタンの onClick 呼び出しと、
  仮想スクロールで DOM に無いファイル用の `POST /pull/<n>/file_review`（GitHub のボタンと同じリクエスト）。
  この手法は [gh-pr-auto-viewer](https://github.com/amitaifrey/gh-pr-auto-viewer)（MIT）を参考にしています。

## 制約・注意

- GitHub の DOM / 内部エンドポイントに依存しているため、GitHub の UI 変更で壊れる可能性があります。
  うまく動かないときは DevTools の Console で `[pr-viewed]` のログを確認してください。
- 巨大な PR で `.diff` が取得できない場合はバッジが `!` になり、何もしません。
- ネストした `.gitattributes` は見ません。
- 送信先は github.com / patch-diff.githubusercontent.com / raw.githubusercontent.com のみ（外部送信なし）。
